**Project Title:** LibraryManagementDB

Project Overview: Our database consists of book data, checkout data, and book availability data that will be used to help students better access the information they need and library staff to have availability information at their fingertips
.  
**Project Purpose**: This database was created to keep all book information in one location. Students and library staff are our key stakeholders and benefit the most from this project.

**Technologies Used:**
- MySQL Workbench - Used to write SQL scripts 
- Excel - Used to create/hold sample data

**Database Features:** Our database allows for students and library staff to easily track book availability via storing reservation information, as well as info regarding books, book copies, publishers, and student borrowing history.
